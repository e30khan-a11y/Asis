# Voice Agent AI - Android Phone Controller

دستیار هوشمند خودکار برای کنترل کامل گوشی اندروید از طریق صدا و بینایی هوش مصنوعی (بدون نیاز به دست).

## قابلیت‌ها:
1. **تشخیص عناصر صفحه به صورت درختی (Accessibility Tree):** دریافت فوری دکمه‌ها، فیلدهای متنی و آیکون‌ها بدون نیاز به اسکرین‌شات سنگین.
2. **پشتیبان بینایی (Vision Fallback):** قابلیت اسکرین‌شات در پس‌زمینه برای صفحات بوم یا گرافیکی که متنی ندارند.
3. **دکمه شناور همیشگی (Floating Mic Overlay):** دکمه میکروفون که روی تمام برنامه‌ها قرار می‌گیرد و با کشیدن انگشت جابجا می‌شود.
4. **موتور هوش مصنوعی Gemini 2.0 Flash:** سرعت فوق‌العاده بالا و درک دقیق زبان فارسی برای انجام سناریوهای چندمرحله‌ای (مانند باز کردن اس‌ام‌اس، تایپ پیام، ارسال و بازگشت به خانه).
5. **ناوبری کامل سیستمی:** قابلیت زدن دکمه‌های Back، Home، Recents و باز کردن هر برنامه نصب‌شده روی گوشی.

---

## نحوه بیلد و ساخت فایل نصبی (APK):

### روش ۱: از طریق Android Studio
1. پوشه `voice_agent_android` را در **Android Studio** باز کنید (Open Project).
2. منتظر بمانید تا کتابخانه‌ها دانلود شوند (Gradle Sync).
3. از منوی بالا گزینه **Build > Build Bundle(s) / APK(s) > Build APK(s)** را بزنید.
4. فایل `app-debug.apk` ساخته شده را روی گوشی خود نصب کنید.

### روش ۲: بیلد رایگان ابری از طریق GitHub Actions (بدون نیاز به نصب نرم‌افزار روی کامپیوتر)
1. این پوشه را در یک ریپازیتوری گیت‌هاب (حتی خصوصی / Private) قرار دهید.
2. به تب **Actions** در گیت‌هاب بروید؛ ورک‌فلو به طور خودکار اجرا شده و در انتهای بیلد، فایل نصبی `VoiceAgent-Debug-APK` برای دانلود مستقیم آماده خواهد بود.

## نحوه راه‌اندازی روی گوشی:
1. بعد از نصب برنامه، وارد آن شوید.
2. کلید رایگان **Gemini API Key** خود را وارد کرده و دکمه «ذخیره» را بزنید.
3. سه دسترسی خواسته شده را فعال کنید:
   * **سرویس دسترسی (Accessibility):** در تنظیمات گوشی برنامه Voice Agent را روشن کنید.
   * **مجوز نمایش روی سایر برنامه‌ها (Overlay):** تیک آن را فعال کنید.
   * **مجوز میکروفون:** تایید کنید.
4. دکمه **«شروع دستیار شناور»** را بزنید.
5. دکمه میکروفون روی صفحه ظاهر می‌شود؛ هر زمان آن را لمس کنید، می‌توانید به فارسی یا انگلیسی دستور دهید تا گوشی آن را به صورت خودکار انجام دهد.
